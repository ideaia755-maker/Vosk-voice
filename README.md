# AURA Voice Injector (12px Nano Pill)

Минималистичный голосовой ассистент-диктовщик уровня ОС в стилистике дизайн-системы **DS AURA (Liquid Mercury Signature)**.

Превращает речь в текст (STT) в реальном времени и автоматически вставляет результат (`Ctrl+V`) в активное окно — будь то чат **Antigravity**, консоль **Codex** или веб-интерфейс **DeepSeek**.

## Особенности
- **Нано-размер:** Высота капсулы ровно 12 пикселей.
- **100% прозрачность:** Истинное прозрачное парящее окно поверх всех приложений без рамок и фоновых подложек.
- **Физика Liquid Mercury:** 10 хромированных мета-сфер вращаются по математическим формулам оригинального `liquid-mercury-physics.ts` из DS AURA.
- **Zero-Click инжекция:** Текст вставляется прямо под курсор при отпускании скролла мыши.
- **Single-Instance защита:** Системный Win32 Mutex предотвращает задвоение процессов.
- **Системный трей:** Иконка в трее Windows рядом с часами с быстрым выходом.
- **Оффлайн работа:** Локальное распознавание речи на базе модели Vosk.

## Горячие клавиши
- **Зажатие правой кнопки мыши (ПКМ, Hold-to-Talk > 0.28с):** Начать запись речи (шары начинают активное вращение). Быстрый клик ПКМ по-прежнему открывает контекстное меню!
- **Отпускание правой кнопки мыши:** Остановка записи, распознавание и вставка текста в активное поле ввода.
- *(Также поддерживается зажатие колёсика мыши).*

## Установка и запуск

1. Установите зависимости:
```bash
pip install vosk sounddevice pynput pyperclip pillow pystray
```

2. Скачайте модель распознавания речи (русский язык):
```bash
python download_model.py
```

3. Запустите приложение:
```bash
run.bat
# или
python app.py
```
